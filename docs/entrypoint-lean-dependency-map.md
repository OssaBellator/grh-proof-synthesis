# From the five Lean targets to the first arithmetic input

**Source-text inspection, 20 November 2026 UTC.** All five declarations converge on `allChi`. The first arithmetic input exposed by the wrappers is `UpperTheory.FinalTheorems.everyCharacter`. Reducing the critical-line statements to this input leaves the central nonvanishing problem intact. This map records names actually used in the small files listed below. We did not elaborate terms or extract a transitive kernel dependency graph.

## What the propositions say

- Official Mathlib defines `RiemannHypothesis` at lines 185–186. For complex $s$ with `riemannZeta s = 0`, it excludes `s = -2 * (n + 1)` for any natural $n$ and `s = 1`, and concludes `s.re = 1 / 2`. The project’s `RiemannZetaZerosOnLine` writes out the same conditions with an explicit coercion. [Pinned Mathlib declaration](https://raw.githubusercontent.com/leanprover-community/mathlib4/0df444a360eaa60ab8c11dca51a86af692955474/Mathlib/NumberTheory/LSeries/RiemannZeta.lean) · [Statements](https://raw.githubusercontent.com/CocoSgt/riemann-hypothesis-lean/0fb9869c6e6d7b54b67de803af0e0be29d37fc22/src/Statements.lean)
- The three Dirichlet predicates are defined in Statements, which imports Mathlib alone. Each quantifies over natural `N` with `[NeZero N]` and `χ : DirichletCharacter ℂ N`. The half-plane predicate assumes `1 / 2 < s.re` and `χ ≠ 1 ∨ s ≠ 1`. Thus it omits the principal character **at the point** 1, keeps nonprincipal characters at 1 and keeps principal characters elsewhere in the half-plane. Its conclusion is `DirichletCharacter.LFunction χ s ≠ 0`. [Statements](https://raw.githubusercontent.com/CocoSgt/riemann-hypothesis-lean/0fb9869c6e6d7b54b67de803af0e0be29d37fc22/src/Statements.lean)
- Both strip predicates require `0 < s.re`, `s.re < 1` and a zero of that same L-function. They conclude `s.re = 1 / 2`. Only the fifth target requires `χ.IsPrimitive`. Neither strip includes its boundary lines. In particular a zero from an imprimitive Euler factor on Re(s) = 0 is outside these predicates. These are Dirichlet characters over the rationals. A general number-field Hecke assertion would need a different target. [Statements](https://raw.githubusercontent.com/CocoSgt/riemann-hypothesis-lean/0fb9869c6e6d7b54b67de803af0e0be29d37fc22/src/Statements.lean) · [Mathlib change-of-level identity](https://raw.githubusercontent.com/leanprover-community/mathlib4/0df444a360eaa60ab8c11dca51a86af692955474/Mathlib/NumberTheory/LSeries/DirichletContinuation.lean)
- Mathlib’s continuation file defines `LFunction` using `ZMod.LFunction` (line 61). Its modulus-one lemma (67), change-of-level identity (150) and principal-character formula away from 1 explain why a semantic audit needs both conductor reduction and a pole convention. Lean’s function takes a value at every complex input. An equality evaluated at 1 requires its own hypotheses. [Official definitions and lemmas](https://raw.githubusercontent.com/leanprover-community/mathlib4/0df444a360eaa60ab8c11dca51a86af692955474/Mathlib/NumberTheory/LSeries/DirichletContinuation.lean)

## Where the source trace stops

1. **Zeta.** `Formalism.VW.rh_of_every` specializes the half-plane assertion to modulus one and invokes `LFunction_modOne_eq` and `Formalism.VW.rh_of_right`. The latter unfolds Mathlib’s RH and uses the zeta functional equation on the left of the line. [CritLine](https://raw.githubusercontent.com/CocoSgt/riemann-hypothesis-lean/0fb9869c6e6d7b54b67de803af0e0be29d37fc22/src/Formalism/GammaFactorNonvanishing/CritLine.lean) · [RhOfRight](https://raw.githubusercontent.com/CocoSgt/riemann-hypothesis-lean/0fb9869c6e6d7b54b67de803af0e0be29d37fc22/src/Formalism/GammaFactorNonvanishing/RhOfRight.lean)
2. **Primitive and imprimitive characters.** The source of `Formalism.VW.critLine` uses the functional equation for the inverse primitive character at $1-s$ and gamma-factor nonvanishing. In `Claim.strip`, the left-of-line branch calls `Claim.prim_zero` and `Claim.prim_reflect`. The right-of-line branch directly uses the half-plane hypothesis. `Claim.prim_zero` uses Mathlib’s change-of-level formula and `Claim.factor_ne_zero`. These are candidate small lemmas for extraction. [CritLine](https://raw.githubusercontent.com/CocoSgt/riemann-hypothesis-lean/0fb9869c6e6d7b54b67de803af0e0be29d37fc22/src/Formalism/GammaFactorNonvanishing/CritLine.lean) · [ClaimStrip](https://raw.githubusercontent.com/CocoSgt/riemann-hypothesis-lean/0fb9869c6e6d7b54b67de803af0e0be29d37fc22/src/Development/AutomorphicArithmetic/CharacterBoxes/ClaimStrip.lean)
3. **Arithmetic input.** `UpperTheory.EveryCharacter` spells out the same half-plane and pole guard. In MainConclusion, `UpperTheory.FinalTheorems.everyCharacter` applies `UpperTheory.FinalTheorems.everyCharacter_of_row` to `UpperTheory.Gal.Int.galoisLocalGlobalStrong_recParameter`. The row lemma invokes `UpperTheory.LiteratureTheorems.every_character_of_literature_of_vWin`, `UpperTheory.Zero.LLC.recTExists` and `UpperTheory.One.vwin_of_row`. Their definitions, the analytic estimates, and any quantified cost of iterating theta lifts lie beyond this trace. The four-page narrative supplies no further formal edge. [EveryCharacter](https://raw.githubusercontent.com/CocoSgt/riemann-hypothesis-lean/0fb9869c6e6d7b54b67de803af0e0be29d37fc22/src/Development/AutomorphicArithmetic/CharacterBoxes/EveryCharacter.lean) · [MainConclusion](https://raw.githubusercontent.com/CocoSgt/riemann-hypothesis-lean/0fb9869c6e6d7b54b67de803af0e0be29d37fc22/src/Development/AutomorphicArithmetic/CharacterBoxes/MainConclusion.lean)
