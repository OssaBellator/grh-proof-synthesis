# Deferred alternative routes

This file is deliberately **not** the current focus.

- Hilbert–Pólya self-adjoint spectral interpretation and generalizations to Dirichlet characters.
- Real-zero approximants with locally uniform convergence and careful nonzero-limit condition.
- Weil's positivity criterion, including exact sum-of-squares/operator decompositions.
- Nyman–Beurling-style density/closure criteria.
- Arithmetic square-root cancellation for twisted Möbius or von Mangoldt sums.

For each, demand an explicit equivalent criterion, a genuinely new lemma, and a noncircular path to Dirichlet GRH. Do not confuse restating an equivalent criterion with proving it.

**Revisit trigger:** at least one source-derived lemma has been independently checked or a precise obstruction documented.
