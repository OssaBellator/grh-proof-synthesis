# Contributing

We welcome rigorous analysis, formal-audit reports, simplification attempts, and carefully documented failures.

## Pull request policy

- Keep source-derived claims and new conjectures in separate commits where practical.
- Do not label a new proof established without reproducible evidence and independent review.
- Never silently replace the original argument's hypotheses by stronger ones.
- Cite primary sources, preserve attribution, and do not paste copyrighted manuscripts.
- For code: add deterministic tests, document environment versions and error messages.
- Disagreement is welcome; personal attacks and unsubstantiated certainty are not.

## Security

Do not run unreviewed scripts from upstream proof archives in a privileged environment. Do not commit credentials or full externally hosted archives without permission and provenance.
