# Repository agent instructions

This repository concerns **unverified claims** to prove the Generalized Riemann Hypothesis (GRH). Neither proposal is an established theorem here.

## Operating rules

- Work only on this repository's contents. The underlying CLI may run with full system access at the user's explicit request; that access is **not** permission to read personal files, credentials, browser profiles, or unrelated projects, or to alter global settings.
- Prefer author-owned primary sources with exact URLs, version dates, physical PDF pages or theorem labels, and verbatim mathematical statements where feasible. Attribute conjectural descriptions.
- Do not present heuristic connections as mathematical results; separate authors' claims, source-inspected content, independently verified lemmas, and speculative hybrid ideas.
- Do not execute any fetched scripts or giant third-party Lean archives without a prior audit.
- No `sorry` or `admit` in a file labeled as a verified Lean lemma.
- Avoid giant copies of externally copyrighted PDFs/Lean archives in Git.
- Do not push or make GitHub issues/PRs automatically; prepare local commits or changes for review.
- Never claim a local source check, Lean build, test, or peer review that was not actually executed.
- Research should be sized to an independently checkable first pass, not an attempted 940-page verification.
